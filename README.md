# CMD-Browser
A simple web browser I am working on that can easily be expanded upon. You can use it to easily browse the and read things. It runs extremely light and uses very minimal resources, allowing for it to run on almost anything with no freezes or slowdowns. As an added bonus, it is privacy-focused, because there is no tracking, telemetry, or anything stored in the browser because it isn't coded in!

# How it works/How to use
Simply type a full url (ie: https://en.wikipedia.org/wiki/computer) and press enter, it will bring up the webpage ready for you to read! You can also use commands to improve your experience!

Commands:
exit: closes the browser
previous: runs the previous command/website

# Notes:
It was originally created in java, and unfortunately when it was converted to C# some of the structure to the code got a bit messed up but it is still generally there.
